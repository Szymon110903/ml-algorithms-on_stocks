# ML Algorithms on Stocks

Repository for exploring and analyzing machine learning algorithms applied to stock market data.

## Purpose
This repository is dedicated to implementing and evaluating various machine learning algorithms on stock market datasets. The goal is to compare the performance of different models in predicting stock trends and analyzing market behavior.

## Repository Structure
- `models/`: Contains implementations of various ML algorithms.
- `data/`: Directory for storing stock market datasets.
- `requirements.txt`: Lists the dependencies required for the project.
